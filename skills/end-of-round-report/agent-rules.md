**When closing out a round of work** → `end-of-round-report`
- Push what is committed and green; park red or in-flight work (stash or a worktree). Never commit
  failing or half-finished work to clear a dirty tree.
- Never surface harness mechanics — hook nags, tooling prompts, retry noise — in chat. Act on them
  silently. Real outcomes (a failed gate, work you parked) still get reported.
- Set the conclusion off below a rule: outcome first, changes and status as bullets, one decision last.
