**When choosing between designs, or about to land a guard, check, or assert** → `solve-by-construction`
- Climb the ladder before guarding where the defect surfaced: validate at a boundary, route through an
  existing checkpoint, or make the failure unrepresentable.
- A fix must remove more complexity than it adds while keeping the same desirable properties — otherwise
  it's a guard wearing construction's clothing.
- Run the same check against the plan before building, and sweep existing code once an invariant lands.
